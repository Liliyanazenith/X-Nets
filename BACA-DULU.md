# Update X'Nest

1. Supabase > SQL Editor: tempel isi `update.sql`, lalu Run. Jalankan juga `update-komentar.sql` (komentar gaya Facebook). Keduanya aman diulang.
2. Upload ke root repo (sejajar dengan index.html): `update.js`, `sw.js`, `manifest.json`, folder `icons/` dan `assets/`.
3. Di `index.html`, tambahkan satu baris tepat sebelum `</body>`:
   `<script src="update.js"></script>`

Yang baru: top up Mora oleh dev (Menu dev > Top up), Menu dev > Sandi semua (Aman / Tidak pantas), harga centang biru 500 Mora per bulan, Kelola saluran/komunitas (tombol gir di header), kartu pratinjau video di Unduh TikTok, bubble pesan kustom (Pengaturan, khusus terverifikasi), PWA (bisa dipasang di layar utama).
Komentar gaya Facebook: tap tombol komentar di kiriman membuka panel komentar (Suka, Balas, hapus), plus pratinjau komentar di bawah kiriman.
